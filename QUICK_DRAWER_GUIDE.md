# 🎯 Quick Drawer Guide - 30 Seconds!

## How to Switch Language

### Step 1: Open Drawer (Choose One)
```
Option A: Tap ☰ (menu icon in top-left)
Option B: Swipe from left edge →
```

### Step 2: Tap Your Language
```
🌍 Select Language

○ English          ← Tap for English
○ ไทย (Thai)       ← Tap for Thai
○ 中文 (Chinese)   ← Tap for Chinese
```

### Step 3: Done!
```
✨ App switches instantly
💾 Choice saved automatically
🎉 Enjoy your language!
```
